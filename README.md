# Che-Yung Shen

Personal site: [stevenshen121200.github.io](https://stevenshen121200.github.io)

Static one-page site. No build step.

## Run locally

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

Edit copy in `index.html` and papers in `data/publications.js`. To change the headshot, replace `assets/portrait.jpg`.
